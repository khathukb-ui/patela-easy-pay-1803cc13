# Patela Easy Pay

A modern payment solution built with React, TypeScript, and Vite.

## Getting Started

### Prerequisites

- Node.js (recommended: install via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating))
- npm

### Installation

```sh
# Clone the repository
git clone https://github.com/khathukb-ui/patela-easy-pay-1803cc13.git

# Navigate to the project directory
cd patela-easy-pay-1803cc13

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies

- **Vite** – Fast build tool and dev server
- **TypeScript** – Type-safe JavaScript
- **React** – UI library
- **shadcn-ui** – Accessible component primitives
- **Tailwind CSS** – Utility-first CSS framework

## Project Structure

- `src/` – Application source code
- `backend/` – Backend services
- `supabase/` – Supabase configuration
- `public/` – Static assets
